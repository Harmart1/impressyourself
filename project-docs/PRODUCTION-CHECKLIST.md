# Production launch checklist

## GitHub Pages
1. Upload this package to the root of `Harmart1/impressyourself`.
2. In GitHub: Settings → Pages → Deploy from a branch.
3. Branch: `main`; folder: `/ (root)`.
4. Confirm `https://harmart1.github.io/impressyourself/` loads with the butterfly logo and full styling.

## Booking calendar
1. Deploy `google-calendar/Code.gs` from the Google account whose calendar Kelly will use.
2. Copy the Apps Script `/exec` URL.
3. Insert it into the calendar endpoint meta tag in `index.html` following `google-calendar/GOOGLE-CALENDAR-SETUP.md`.
4. Test one booking and verify the event appears in Google Calendar and confirmations send correctly.

## Search / local visibility
- Submit `sitemap.xml` in Google Search Console.
- Link the website from the Google Business Profile.
- Keep business name, address, email and service wording consistent across public listings.
- Add genuine project photos and client reviews when available; do not fabricate testimonials.

## Final content verification
- Confirm the postal code and public meeting-address wording before launch.
- Confirm current service durations and booking options.
- Recheck local donation / City waste links quarterly.
