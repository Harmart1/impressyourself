# impressyourself — production brand guide

## Brand idea
**Organize the space. Optimize the system.**

The butterfly mark represents transformation through two balanced wings: **physical space** and **systems/process**. The centre line represents flow — the point where a well-organized environment and a usable operating system meet.

## Primary palette
- Raspberry `#B21F4A` — action, progress, transformation
- Cream `#FBF7F2` — calm, space, possibility
- Charcoal `#303735` — structure, professionalism
- Sage `#A8B2A0` — order, balance, grounded improvement
- Blush `#E5C2C1` — warmth and approachability

## Logo files
- `impressyourself-butterfly-logo.svg` — primary mark for light backgrounds
- `impressyourself-butterfly-logo-reverse.svg` — reverse mark for dark backgrounds
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` — browser/device icons

Keep clear space around the mark equal to approximately one quarter of its width. Do not stretch, rotate permanently, add shadows to the source artwork, or recolour the primary mark outside the approved palette.

## Typography
The production website deliberately uses system-safe fonts for speed and reliability:
- Serif: Georgia / Times New Roman fallback for editorial headings and wordmark treatment
- Sans-serif: Inter when available, then native system UI fonts

## Voice
Practical, calm, capable and specific. Avoid language that makes organizing sound purely aesthetic. Lead with function, clarity, reduced friction, easier retrieval, easier resets, repeatable processes and better flow.

## Core phrases
- Organize the space. Optimize the system.
- Clear space. Clear systems. More room for what matters.
- Organized spaces. Smarter systems.
- Less searching. Clearer next steps. Easier resets.
